About this model

Model
Calibrated Linear SVM over TF-IDF features (unigrams + bigrams)
Sentiment classes
Negative, Neutral, Positive — derived from a 1–5 star rating convention (1–2 → Negative, 3 → Neutral, 4–5 → Positive)
Trained on
22,634 real e-commerce clothing reviews
Research
Full experimental comparison against Logistic Regression, Naive Bayes, and a DistilBERT transformer baseline is in the project notebook.

ProductSentimentML — a comparative NLP research project. Not intended for high-stakes automated decisions.
